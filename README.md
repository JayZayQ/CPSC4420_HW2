# CPSC4420_HW2
Repository for AI hw2
This project uses Gymnasium's FrozenLake 8x8 environment

Setup
Windows:
Open terminal in project's folder

Make a virtual environment:

py -m venv .venv

Then run:

\.venv\Scripts\activate

Next get libraries:

python -m pip install --upgrade pip
pip install "gymnasium[toy-text]" numpy matplotlib

Run:
python C_baseline.py
